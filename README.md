## The entry

One word: **kiowayyy** — the account's own make.fun username, sent as a
single word and nothing else.

No slogan, no punchline, no extra characters. The handle itself is the
entry: eight characters, one word, instantly readable, and the name the
account already goes by on make.fun.

## How to run

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when the variable is unset). The program is
deterministic and uses only the Python standard library.
